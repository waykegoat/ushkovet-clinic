# Памятка по запуску сайта

Сайт готов к размещению на постоянном домене. В текущей версии запись происходит по телефону: онлайн-форма и необходимость мониторить обращения удалены.

## Покупка домена `ushkovet-clinic.ru`

1. Откройте сайт регистратора, например [REG.RU](https://www.reg.ru/), и проверьте имя `ushkovet-clinic.ru`.
2. Если имя свободно, зарегистрируйте его на владельца клиники или на юридическое лицо клиники. Не оформляйте домен на разработчика.
3. Укажите реальные паспортные/организационные данные, рабочий email и телефон владельца.
4. Подтвердите email и личность администратора домена через подтверждённую учётную запись Госуслуг, если регистратор запросит это.
5. Включите двухфакторную авторизацию и автоматическое продление. Сохраните договор, логин и резервный email.

По правилам регистрации `.ru` регистратор может запросить достоверные данные администратора. REG.RU также предупреждает об обязательной идентификации операций с `.ru`, `.рф` и `.su` с 1 сентября 2026 года, поэтому лучше пройти её сразу.

## Подключение купленного домена к Cloudflare

1. В Cloudflare откройте **Onboard a domain** и добавьте `ushkovet-clinic.ru` без `https://`.
2. Выберите бесплатный план и дождитесь, пока Cloudflare выдаст два nameserver-адреса.
3. В кабинете регистратора откройте домен → **DNS-серверы** → **Свой список** и замените текущие nameserver-адреса на два адреса Cloudflare.
4. Не удаляйте MX/TXT-записи, если у клиники уже есть корпоративная почта.
5. Дождитесь делегирования DNS. Обычно это занимает от нескольких минут до 24 часов.

После этого сообщите мне: домен куплен, nameserver-адреса заменены, Cloudflare показывает статус **Active**.

## Что потребуется от вас

1. Домен для сайта, например `ushkovet.ru`. Если домен уже куплен, нужен доступ к личному кабинету регистратора только на время настройки DNS.
2. Учётная запись Cloudflare. Зарегистрируйтесь на https://dash.cloudflare.com/ и добавьте меня в команду с правами **Administrator** на время настройки.
3. Доступ к репозиторию сайта на GitHub: https://github.com/waykegoat/ushkovet-clinic. Достаточно добавить меня в проект с правами **Write**.
4. Email, который будет использоваться для входа в панель управления сайтом.
5. Подтверждение телефона клиники: `+7 (999) 138-54-61`.

## Техническая установка для разработчика

Команды выполняются в корне проекта в PowerShell:

```powershell
npm install
npx wrangler login
```

Для текущей версии с записью по телефону D1 не нужна: сайт работает со стартовым контентом из сборки. Поэтому сразу выполните:

```powershell
npm run deploy
```

Панель `/admin` и редактирование контента подключаются отдельно, если клинике это понадобится. Тогда создайте D1:

```powershell
npx wrangler d1 create ushkovet-production
```

После создания D1 добавьте в `wrangler.toml` блок, подставив выданный Cloudflare `database_id`:

```toml
[[d1_databases]]
binding = "DB"
database_name = "ushkovet-production"
database_id = "ВАШ_DATABASE_ID"
```

Инициализируйте удалённую базу:

```powershell
npx wrangler d1 execute ushkovet-production --remote --file=./drizzle/0000_lonely_winter_soldier.sql
```

После этого снова соберите и опубликуйте Worker со статическими файлами:

```powershell
npm run deploy
```

В Cloudflare откройте Worker `ushkovet-clinic` → **Settings** → **Domains & Routes** → **Add Custom Domain** и укажите основной домен. Домен должен быть добавлен в Cloudflare, а его DNS-серверы — направлены на Cloudflare. Custom Domain автоматически создаёт маршрут Worker и HTTPS-сертификат.

После публикации проверьте:

- открывается главная, `/services` и `/contacts`;
- телефонные кнопки открывают `tel:+79991385461`;
- карта показывает Верхне-Печёрскую улицу, 14;
- сайт открывается по HTTPS на основном домене;
- в браузере нет ошибок загрузки изображений.
