# Что нужно для запуска сайта

Здравствуйте! Чтобы разместить сайт ветеринарной клиники на постоянном адресе и включить онлайн-заявки, пожалуйста, подготовьте доступы из списка ниже. Пароли в переписке не отправляйте — лучше добавить меня как временного администратора.

## Что потребуется от вас

1. Домен для сайта, например `ushkovet.ru`. Если домен уже куплен, нужен доступ к личному кабинету регистратора только на время настройки DNS.
2. Учётная запись Cloudflare. Зарегистрируйтесь на https://dash.cloudflare.com/ и добавьте меня в команду с правами **Administrator**.
3. Доступ к репозиторию сайта на GitHub: https://github.com/waykegoat/ushkovet-clinic. Достаточно добавить меня в проект с правами **Write**.
4. Email, который будет использоваться для входа в панель управления сайтом.
5. Адрес, на который должны приходить уведомления о новых заявках. Если уведомления нужны в Telegram или VK, пришлите ссылку на нужный чат/сообщество и назначьте администратора, который может добавить бота.

## Что сделаю я

1. Подключу домен и включу HTTPS.
2. Размещу сайт, базу заявок и закрытую панель управления на одной платформе.
3. Настрою вход в `/admin` по вашему email и отдельному паролю.
4. Перенесу все настройки, проверю форму записи, карту, мобильную версию и индексацию.
5. Передам адрес сайта, адрес админки и короткую памятку по работе с заявками.

## Срок и результат

После получения доступов и подтверждения контактных данных техническая настройка обычно занимает один рабочий день. До переключения домена сайт можно спокойно согласовать по демонстрационной ссылке.

## Важно

GitHub Pages используется только для демонстрации дизайна. На постоянном сайте заявки сохраняются в базе данных и доступны в закрытой админке; для этого сайт разворачивается в Cloudflare Workers вместе с базой D1.
